---
name: Course gallery preview
description: Selection and visibility rules for Gallery images reused on course detail pages.
---

A per-image `showOnCoursePreview` toggle in Gallery settings controls whether a published gallery image appears on every course detail page. Keep it independent from `showOnHome`; order selected images by their existing Gallery position. Do not add faculty eligibility, subject matching, or per-course selection.

**Why:** The user confirmed a single global checkbox should control all course pages and that gallery selection does not need the Faculty eligibility rules.

**How to apply:** Keep Gallery settings as the source of selection, require normal public visibility, omit the preview when nothing is selected, and reuse the college's existing theme and Gallery copy.
